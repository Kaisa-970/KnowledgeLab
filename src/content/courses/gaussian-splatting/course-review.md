## 历史问题与返工依据

初版 `e57be6f` 的实际学习者评分为 **6/10**，是反向基准，不是当前修订版的评分。初版反例及推导占正文 82/184 行，却缺少“二维协方差 → 每个像素的权重 → 有序颜色合成”的桥梁。数学模块已有 `gaussianFalloff` / `alphaAt` / `footprintOpacity`，正文和图却没有解释或使用这条链。

另一个可复现错误是合成顺序：图从远层 α=0.45 开始前向累加，得到按远→近排列的权重 0.450 / 0.1925 / 0.10725；正确的近→远权重为 0.300 / 0.245 / 0.20475。两种遍历的权重总和都是 0.74975、最终透射率都是 0.25025，原有测试只看总数和椭圆数量，因此没有发现逐层分配错误。

历史返工中，实际看图还发现了四个问题：

- 把相对偏移当作绝对屏幕坐标传给 `footprintOpacity`，曲线塌为零、图注出现 Infinity；当前函数文档明确传入绝对坐标，内部减去投影中心。
- 面板标题字号为 0.15 个 viewBox 单位，实际不可见。
- 足迹图的 σ₁ 标签和 2σ 等值线越过图框。
- 俯视图的世界点错误地放在相机与成像平面之间；当前相机在 z=0、成像平面在 z=1、世界点在 z=2 和 z=3，射线交点给出 u=x/z。

此前复核还指出了 JΣJᵀ 的推导跳步、未归一化核与概率密度混淆、o=1 未说明，以及把混合换序影响归因于求和顺序等问题。这些均在当前正文中修正。历史记录中对“跨视角颜色一致”的辩护不再作为当前结论：现文明确球谐可拟合视角相关外观，但不显式表示物理材质与光照机制。

历史版本曾记录 106 项单测、94 项浏览器测试全绿；另一次 Codex 复核记录了 116 项单测通过、完整浏览器测试因加载超时未确认。这些只描述当时的执行范围，均不作为当前验证结果。

## 数学 oracle 与覆盖范围

本课程 **32 条单元测试、30 个 oracle 引用**，均指向实际测试。主要独立依据包括：

- 解析的针孔导数与闭式展宽比，与有限差分、光轴/离轴、各向同性及退化条件比对。
- 将采样增量经 J 映射后取经验协方差，与 JΣJᵀ 比对，并断言它明显不同于直接取左上 2×2 块。对应 `Sigma' = J Sigma J^T follows from applying J to the increments, not to Sigma`。
- 单独代入马氏距离二次型验证衰减；在良态协方差下验证一个 σ 处为 e^(−1/2)，并验证不透明度只等比缩放曲线。
- 混合的手算逐层乘积：进入层的透射率为 1 / 0.7 / 0.455，贡献为 0.3 / 0.245 / 0.20475，剩余透射率为 0.7 / 0.455 / 0.25025。`each layer contribution is incoming transmittance times alpha` 覆盖实际供图使用的函数、反向遍历及远层贡献更大的反例。
- 固定种子 20240513、20000 样本、丢弃 z≤10⁻⁴ 的精确透视采样，与局部仿射公式比较。σ_along=0.5 时样本横向标准差约 0.354，公式预测约 0.125；这是有限样本观察，不是总体标准差，也不是原论文实验数据。未经截断时 x/z 的二阶矩一般发散。
- 浏览器内按独立标量公式复算权重与路径坐标，核对采样点、基线、标记、预设、显示开关和重置，防止数学测试正确但绘图坐标传错。

正文引用 Kerbl 等 2023（arXiv:2308.04079）作为投影协方差、混合与增密规则来源；本轮没有重新独立复核原论文全部公式、代码或实验结果。九张图为程序化原创，无第三方图片许可问题；解析示意与训练模型渲染结果有明确区分。
