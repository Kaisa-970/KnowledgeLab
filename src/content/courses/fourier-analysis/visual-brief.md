# Visual Brief：频率视角与周期特征

- 教学任务：在时间曲线中识别两种振动；区分“在什么时刻变化”与“包含哪些重复节奏”。
- 媒介：独立原创的程序化 SVG（`src/components/FrequencyLensFigure.tsx`），没有外部图片复制与授权需求。
- 数据约定：`x(t)=sin(t)+0.45sin(3t)`；相位 `t∈[0,2π]`；1、3 次谐波幅度为 1、0.45。
- 三行波形：合成值等于基波加第 3 次谐波的逐点和，柱形表示幅度但不含相位。
- 标签与访问性：中文标题、相位弧度、谐波序号；有独立的替代文字与图注，颜色并非唯一信息。移动端上下排列。
- 第三节：灰色目标线在方波 `0` 和锯齿周期接缝处必须真实断开；蓝色有限部分和保持连续。局部观察跟随方波跳变、锯齿接缝、三角折角；放大区间以特征为中心左右各 π/3。
- 验收：根据公式检查曲线频率与高度、显示峰值；人工在桌面和手机检查图示与文字是否清晰。未进行独立人工验收不得标记已完成。
