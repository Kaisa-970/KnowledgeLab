# Learning Brief — 3D Gaussian Splatting：一个椭球在屏幕上占多大？

> 本文是**把规划课程转为实现**，不是新建课程。全局规划中原有 `gaussian-splatting` 占位（`graphics-gpu / neural-rendering`），本轮沿用该 ID，模块先修 `graphics-pipeline` 保持有效。

## Learner State · 学习者状态

- **确认已知**（内部依据，不写入正文）：投影矩阵与齐次坐标、透视除法、屏幕空间重心坐标与属性插值、深度缓冲；图形学管线中每个阶段各自负责什么。
- **合理假设**（未核实）：知道神经网络用梯度下降训练，知道卷积与损失的大致含义；不假设读过 NeRF 或任何辐射场论文。
- **当前卡点**：能解释光栅化三角形的流程，但面对"一个三维高斯投影到屏幕"时会直觉地套用仿射变换——把 $3\times3$ 协方差的左上 $2\times2$ 块取出来除以 $z^2$。这个规则在画面中央正确，所以不会被立即证伪。
- **本次目标/期望深度**：理解足迹从哪来（主线）→ 推导雅可比与线性化边界（深入）→ 知道训练与排序为什么这样设计（工程）。
- **应省略或只链接的基础**：不再讲投影矩阵来源、不再讲重心坐标定义、不复述梯度下降。

## Cognitive Gap · 核心认知转折

- **一个真实问题**：NeRF 每个像素要采样上百次网络，慢得没法交互；把场景换成显式椭球就能用光栅化，但显式椭球必须先回答"投影后是什么形状"。
- **原模型作出的错误预测**：既然投影是线性的，把协方差的 $2\times2$ 分块按 $1/z^2$ 缩放即可；深度方向的分量对屏幕形状没有影响。
- **反例（可手算）**：横向 $0.01$、深度 $0.5$、在 $(1,0,2)$ 的高斯，朴素规则给出 $0.005$（约 2.5 px 的点），正确的局部仿射足迹是 $0.125$（约 62 px 的长条），**差 25 倍**。
- **Core Insight**：透视投影不是仿射映射，雅可比的第三列把深度的展开折算成了屏幕上的横向展宽；朴素规则等于显式假设这一列为零，而这一列在光轴上消失；各向同性离轴时仍贡献展宽，只是不再有尺度比的放大。

## Minimal Understanding Loop · 最小理解闭环

- **先看到什么**：同一中心、同一横向尺度、不同深度尺度的两个高斯，朴素椭圆完全重合，校正椭圆相差 25 倍（第一张图）。
- **可以预测什么**：把深度尺度从 $0.5$ 降到 $0.01$，两条路径还会不一致吗？把高斯移回光轴呢？
- **哪个结果暴露原模型不足**：光轴上两法**精确**相等（不是近似）——这正说明错误被"中心取景"掩盖，而不是不存在。
- **新模型怎样解释**：$\pi(x,y,z)=(x/z,y/z)$ 的雅可比第三列含 $x/z^2$、$y/z^2$；展宽倍数等于 $\sqrt{1+(x/z)^2(\sigma_\text{along}/\sigma_\text{cross})^2}$，只依赖两个无量纲量。
- **Transfer Check**：保持中心 $(0.5,0,2)$ 不变，把横向与深度尺度同时翻倍，预测轴比、半轴及近似精度如何变化；再把深度尺度拉到 $1.0$，判断公式是否还可信。（正文末节，两个都未直接演示）
- **自然退出点**：能解释朴素规则为何在中心正确、在边缘失效，并能预测平移回光轴与改为各向同性时的不同结果。此时对排序、增密一无所知也不影响这个模型成立。

## Natural Narrative & Core Bridges · 自然叙事与核心跳步

- **一篇讲完，不拆篇**：NeRF 的代价 → 显式图元 → 投影足迹 → 混合排序 → 参数从哪来 → 近似边界，是同一条因果链。拆成"表示/投影/渲染/训练"四篇会迫使读者反复重建上下文。
- **最不能跳过的三个环节**：
  1. **雅可比第三列为什么会非零**——不是"深度被忽略"，而是近端张开角更大、远端更小，深度差异在屏幕上变成横向长度。用俯视图给几何解释。
  2. **$\Sigma'=J\Sigma J^\top$ 是线性化而不是恒等式**——必须诚实说明三维高斯投影后不是高斯，以及为什么这个近似足够好。
  3. **排序为什么是正确性而不是优化**——透射率与顺序无关、颜色与顺序有关，这解释了工程里 tile 级排序的取舍与闪烁现象。
- **只供内部参考、不写入正文的读者背景**：上面 Learner State 的"确认已知"与"合理假设"两栏；正文直接使用这些能力，不作声明。
- **需要准确图示、可核算的机制**：投影足迹对比（两面板共用比例尺）、俯视图的深度到横向折算、特征分解得到的椭圆、前向 α 合成的透射率表、线性化失效的实测曲线。全部由 `src/math/gaussian-splatting.ts` 计算，无手绘数值。
- **检查并删除的模板化内容**：没有"本节目标/现在你掌握了"；没有"你知道吗，其实……"式对读者水平的评判；没有为凑栏目而加的总结段；只有一个交互实验，放在它确实不可替代的位置。

## Progressive Disclosure · 渐进深入

- **主路径**：为什么换表示 → 投影不是仿射 → 雅可比第三列 → 25 倍反例与闭式比值 → 光轴精确一致与各向同性离轴的小误差。
- **Derive / Implement**：可展开的 $J$ 与 $\Sigma'=J\Sigma J^\top$ 推导、无迹变换的替代方案、混合公式、损失函数与自适应增密/剪枝/不透明度重置、tile 级排序的实现取舍。
- **Transfer / Boundary**：光轴精确一致与各向同性离轴仍有误差、线性化在高深度尺度下的失效量化、静态/朗伯/不透明假设的适用边界、与 NeRF 的分工、可编辑性通向资产化。
- **Pressure Risks**：不在同一页同时引入 SH 的球谐基定义与协方差参数化；矩阵符号只出现一次坐标约定说明；不复述投影矩阵。
