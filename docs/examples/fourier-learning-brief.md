# 示例 Learning Brief：傅里叶分析“复杂波形从何而来”

**这是对现有傅里叶课程的建议设计稿，不代表已按此重写 MDX 或修复数学内容。**

## 入口：先遇见现象

两种乐器演奏同一个音高，听起来为何不同？音高关联基频，而**波形细节/谐波结构**关联音色的一部分。仅观察时间曲线不容易看出构成差异。

要把复杂声音中的成分分开，得先回答：能不能用少量**可识别的简单振动**描述复杂振动？

不是把“钢琴声音由一组完美谐波构成”当无条件事实：真实声音还含瞬态、噪声、非谐波成分、包络等，此处只是引出周期振动的数学模型。

## 学习路径

1. **现象**：同基频但不同波形，声音感受为何不同？提供两张合法图或原创波形对照，明确不是同一个声学信号。
2. **朴素尝试**：选最简单的周期振动（正弦）做“积木”。只用一块积木不够；试着叠加不同频率，观察复杂度增加。
3. **难题**：叠加容易，拆分呢？如何从复杂波形中找出每块积木贡献多少？
4. **转折**：认识三角函数的正交性，把“提取某频率成分”理解为“在函数空间投影”；**此刻**才引入内积、积分和系数公式。
5. **检验**：对对称方波做可计算的例子，利用奇偶性去掉一半候选，再推导 `4/(nπ)`。
6. **遇到边界**：增加谐波能逼近跳变吗？Gibbs 现象引出不同收敛概念（逐点 / L² / 一致），不是“级数完全失败”。
7. **回扣**：能分辨/重建哪些频率成分？它对音色分析、滤波、信号处理有什么意义？真实声学哪里超出当前简化模型？
8. **迁移**：如果周期不是 `2π`，谐波序号如何映射物理频率？再引出非周期信号的傅里叶变换。

## 知识连接（必须解释）

- **线性代数·向量投影 → 函数空间投影**：向量内积变成函数乘积的积分，系数求法的思想相同，所处空间不同。
- **傅里叶级数 ↔ 傅里叶变换**：周期信号频率离散；非周期信号通常需要连续频率描述（需要补精确定义与条件）。
- **Gibbs ↔ 均方/一致收敛**：不同误差指标回答不同问题；不能因为离散采样在跳点有误差下限，就说连续域 L² 不收敛。
- **频谱分析 → 滤波**：修改某些频率成分可改变信号，再反向重建近似波形。

## 媒介决策

- 真实音色示例：优先权利明确的授权音频/图；无法授权就用原创合成波形注明“模型示意”。
- 正交性：静态投影示意 + 必要积分推导足够。
- 逐项叠加：交互滑块或阶段图，可以看到“新增谐波 → 部分和 → 残差”。
- Gibbs：需要放大跳变邻域，并显示误差定义/单位；不是只贴 1.179 这个数字。

## 复核注意

当前课程数学仍可能有独立审核发现的问题；改写叙事**不能掩盖数学错误**，例如 `cos(0t)` 的单独归一化、周期端点的 Gibbs 和连续域 RMS 收敛。修改时应同步修正公式、实验及测试。
