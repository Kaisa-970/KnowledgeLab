
# Knowledge Map：透视校正插值

这篇是光栅化管线的**属性插值环节**，不是一篇从头介绍 GPU 的教材。

    顶点变换 → 透视除法 → 屏幕空间重心坐标
                                  ├─ s/w 与 1/w → 恢复三维表面属性 → 纹理采样
                                  └─ z_clip/w → 深度缓冲

## 需要哪些已知知识

- **齐次坐标/投影矩阵**：只需要知道 clip-space 的 $w$ 以及透视除法。齐次坐标的数学来源不是本节目标。
- **重心坐标**：已经会计算屏幕重心权重 $\lambda_i$；本节揭示这些正确的屏幕权重为什么**不能直接当作三维表面权重**。
- **线性代数的仿射映射**：识别 $1/w$ 与 $s/w$ 才是屏幕空间的仿射量，并让 $\lambda_i$ 在正确的空间发挥作用。

## 最重要的知识连接

- **投影矩阵 ↔ 透视除法**：矩阵乘法在齐次坐标中是线性的，最终非仿射性来自除以 $w$。
- **UV 插值 ↔ 深度插值**：UV 是表面上的仿射属性，需插 $s/w$ 与 $1/w$；深度使用 $z_{\rm clip}/w$，它在屏幕上已经是仿射的。
- **插值 ↔ 纹理过滤**：前者关心样本在曲面上的**位置是否正确**，后者关心像素足迹内应如何**汇总样本**。
- **细分 ↔ 透视校正**：对一个正确细分且属性正确赋值的表面，分段朴素插值能够减小误差（这与之前“细分完全无效”的说法相反），但不改变其近似本质；透视校正可在不加顶点的情况下得到精确的表面仿射插值。

删除了先前与傅里叶截断误差的牵强横向连接：两者可以比较，但并不是本节理解 $1/w$ 所需的先修，也不应该为了丰富图谱而写出“细分三角形完全无效”的错误论断。

## 适用边界

推导假定非退化三角形、透视投影以及属性在三维三角形上仿射变化。正交投影的 $w$ 可以是常数，因此屏幕插值与透视校正在此情形下一致。本节不展开 clipping、透视导数、mipmap 与深度精度；它们可作为后续独立主题。
