# Visual Research — 先确立用途，再找图，再核许可

必读：`docs/VISUAL_ASSETS.md`、`docs/templates/visual-brief.md`。

## 触发

当有人要求“给这节配图”、“找论文里的图”、“从官方教程借图”、“比较两个模型的示意图”等，或课程计划列出了需要外部素材的视觉问题。

## 顺序

1. **先写 Visual Brief**：这幅图要解决什么学习障碍？要展示的事实、空间关系和因果是什么？一幅图是否比互动更合适？
2. **查事实优先一手来源**：官方技术文档、研究机构/作者论文、标准、大学课程与原始项目；逐一记录作者/日期/关键条件。
3. **不够清楚再查优质教学资料**：有可信作者和完整推导的博客、教程、公开知识平台，作为解释参考。论坛/聚合只作为线索回溯原始资料。
4. **另行判断图片使用权**：找到图后读取具体图片/页面的许可证或取得书面许可；不要因为页面是官网、大学课程或公开博客就认为图片可嵌入。
5. 依据授权与教学价值选择：
   - 获明确许可 → 本地保存符合许可证的版本、记录署名与改作要求；
   - 版权不清 → 在文字中链接来源，**不复制、不截图、不热链**；
   - 更适合精确概念图 → 交给 `diagram-authoring` 独立设计 SVG；
   - 缺少适合图片且不影响理解 → 不加图片。
6. 为每个入选素材填视觉记录：原始来源 URL、实际许可证依据、作者、访问日期、使用方式、修改说明、alt、caption、核验状态。
7. 审核语义：方向、标注、几何、坐标单位及结果是否与正文一致；技术时效性检查发布时间或版本。

## 实施限制

- 没有联网工具时说明无法核实，不得伪称已搜索。
- 未知许可不得回退为“只需注明来源就可以使用”；引用事实与复制图片是两件事。
- 图片生成并不等同于原创数学证明；不能用生成图伪造论文图、实验输出、设备照片。
- 不为凑图而牺牲叙事。

## 输出

`Visual Brief` + 候选图及来源/使用权判定 + 选择或拒绝理由 + 可执行的原创图需求；**未审查的图不得进入正式课程**。
