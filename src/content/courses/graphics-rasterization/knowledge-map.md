# Knowledge Map：光栅化

本文件解释教学桥梁；机器可读的关系在 `knowledge-map.json`。

## 位置

这则笔记只处理一件事：**顶点之后、属性如何插值**。把它放回管线的位置是：

```
顶点变换 ──► 透视除法 ──► 屏幕空间 ──┬──► 属性插值 ──► 纹理采样（下一节）
   │                                  │
   └── 投影矩阵（线性部分）            └──► 深度缓冲 z/w（不需要校正）
```

`view-clip-space` 与 `barycentric` 是两个独立的先修入口：前者来自投影，后者来自三角形填充。`perspective-correct-interpolation` 正是这两条线交汇的地方——它是"从 2D 屏幕反推 3D 曲面"这个动作的数学核心。

## 上游：用到先修的哪一部分

- **线性变换与矩阵（线性代数课程）**：只用到"矩阵的列是基向量的像"这一个事实，用来说明投影矩阵为什么是线性的、以及为什么线性部分**无法**表达透视。透视除法不是矩阵能做的事，它在矩阵之后。
- **齐次坐标**：只用到 $w$ 作为「第四个分量」这个角色。这里不重新推导齐次坐标的射影几何来源。

## 同层对比

**与傅里叶的对照是这里最有价值的一条横向连接。** 两者都在处理"用简单的东西逼近更复杂的对象，但误差始终存在"：

| | 傅里叶级数 | 透视插值 |
| --- | --- | --- |
| 误差来源 | 基函数个数有限，截断在跳变处 | 权重取自错误的坐标空间 |
| 增加"分辨率"能改善吗 | 能，但过冲不消失 | **不能**，细分三角形完全无效 |
| 有跳变吗 | 有，正是误差集中的地方 | 没有，函数本身光滑 |

这个对照能防止一种常见的错误迁移："既然傅里叶加项能逼近，那我细分三角形也能逼近。"细分只是把同样的错误权重用在更小的三角形上。

## 下游迁移

- **纹理过滤**：笔记解决"插在哪"，filtering 解决"采多少"。两者独立：即使插值完全正确，斜视平面的远处纹理仍会走样。
- **`ddx`/`ddy` 与手工重建视空间**：shader 里做屏幕空间导数运算时，会再次遇到"这个量在哪个空间线性"的同一问题。这里的判据（$z/w$ 屏幕空间仿射，$z$ 视空间线性）直接适用。
- **深度精度与 z-fighting（规划中）**：由 $z_{\text{ndc}}=A+B/w$ 可以看出深度在缓冲区里是非线性分布的，以及为什么近平面放太近会毁掉远处精度。这个表达式本身尚未在正文里给出，留待后续条目。

## 边界

- 不涉及齐次坐标的射影几何来源，也不涉及裁剪（clipping）阶段。
- 不提供实现代码，这是体裁决定。
- 全部讨论假定标准透视投影与硬件式深度缓冲。正交投影下 $w$ 恒定，这里的现象完全消失——这不是"退化情况"，是一个应当能被自己推出来的边界。
