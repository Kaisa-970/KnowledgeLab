
# Curriculum Contract v1 — 先定位知识，再决定课程

本规范优先于 Learning Experience Contract 与 Course Contract v2。**每个新学习问题先找已有知识位置，不自动新建一门课程。**

## 全局目录与知识网络

- 唯一规划来源：`src/content/curriculum/curriculum.json`，Schema：`schemas/curriculum.schema.json`。
- 组织层级：**Track 学科主线 → Module 专题模块 → Course 课程 → Chapter 章节 → Concept 知识节点**。
- `courseIds` 表示实际课程；`plannedCourses` 仅表示未来主题与范围（`scope`），不是已完成课程。规划课程被实现时，要保持 ID，从 planned 移入同模块的 courseIds。
- 需要细化的规划课可增加 `learningDesign`：具体先修能力、可检查目标、带先修依赖的章节路线与内部 Brief 路径。它仍是规划，不能提供假章节链接；实现时迁入正式计划并移除原规划，不维护两份路线。目录按需展示路线，并以锚点显示模块先修；先修不等于强制阅读顺序。
- 每门实际课程通过 `curriculum.trackId/moduleId` 指明**唯一主归属**，并匹配全局目录。`domain` 是粗领域标签。跨领域关系继续由 `knowledge-map.json` 表达为网状链接，不在两条主线复制同一门课程。
- `dependsOnModuleIds` 只用于有根据的模块级先修关系。个人可以基于已知能力跳过上游内容；树状归属不是个人必须遵循的阅读顺序。
- 五条主线（数学、图形学与 GPU、机器学习与生成模型、机器人与空间智能、计算机系统）是可演进的**初始系统规划**。

## 接到新问题：必须先检索和定位

在决定创建任何 MDX/Course 前，Agent 查全局目录、现有与规划的 course.plan.json、knowledgeNodes、章节和跨课程知识图。给学习者简短定位：

> **知识位置**：学科主线 → 模块 → 课程 → 章节 / 概念；标注已有或规划中。只指出真正有用的先修、对比或下游连接。

随后选择最小动作：

| 当前情况 | 默认处理 |
| --- | --- |
| 已有章节/知识节点 | **直接解答或引用现有章节**，不必改仓库 |
| 章节有错或解释不清 | **修改原章节和相应实验**，保留 ID |
| 现有课程缺关键的认知过渡 | **新增或解锁该课程的章节**，不创建新课程 |
| 涉及多个学科 | **确定主要归属，再用知识关系连接应用**，不复制课程 |
| 已有课程不能承载持续独立的学习主题 | 先解释独立性、长期范围与章节路线；优先复用 plannedCourses 的稳定 ID |
| 模块也不合适 | 先提出结构迁移/扩展理由，再修改主树 |

**新课程人工审查**必须说明：检索过哪些现有课程与同义节点？为什么扩充它们不够？新课程独立目标、可持续章节路线和边界是什么？挂在哪个 Track/Module，相关先修/应用如何连接？为什么现在由规划转为实现？普通问题无须添加课程。

## CI 真正能阻止什么

`npm run validate` 能拒绝：全局目录 Schema 错误、重复 Track/Module ID、未知或成环的模块先修、实际课程未登记或重复登记、课程 plan 与目录的归属/领域矛盾、未知 courseIds、规划 ID 重复或与已实现课程并存。

**CI 无法判断语义重复或课程必要性。** Agent 同次提交 manifest 与新课程，也可能结构合法但课程重复；独立性是维护者的内容审核项。不能谎称机器验证了“不会随便建课”。

## 五个常见问题应该怎样归属

- **PCA 最大方差 vs 点云法线最小方差**：数学基础 → 线性代数 → 协方差/PCA（规划章节）；点云应用与空间感知通过关系连接，不新建“PCA 与法线”课程。
- **透视校正为何除以 w**：图形学与 GPU → 图形渲染管线 → 光栅化（已有章节）。
- **VAE 与 Diffusion 区别**：机器学习与生成模型 → 生成模型 → 生成模型系统课程（规划），不能每一个模型单独建顶层课。
- **3DGS tile 排序**：图形学与 GPU → 神经渲染与 3DGS → Gaussian Splatting（规划），连接 GPU 计算模块。
- **BC 与 RL 差别**：机器人与空间智能 → 机器人学习 → 机器人策略学习（规划），属于同一条学习主线。

公开仓库保存的是非识别性的知识结构，不保存具体学习者“哪些已掌握”的敏感个人状态。个性化路径应基于获授权的私人上下文选择知识树节点。
