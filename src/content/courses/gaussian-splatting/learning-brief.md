# Learning Brief — 3D Gaussian Splatting：椭球怎么变成像素？

> 本文是**把规划课程转为实现**，不是新建课程。全局规划中原有 `gaussian-splatting` 占位（`graphics-gpu / neural-rendering`），沿用该 ID。
>
> **2026-10-14 修订**：初版把"朴素规则低估 25 倍"当作核心认知转折，读者反馈 6/10。修订后的核心转折改为**「屏幕上的协方差怎样变成每个像素的不透明度」**——即从几何量到渲染量的那一步；反例降级为这条链的一个支撑检查。改动范围见本文档末尾与 `course-review.md`。

## Learner State · 学习者状态

- **确认已知**（内部依据，不写入正文）：投影矩阵与齐次坐标、透视除法、屏幕空间重心坐标与属性插值、深度缓冲；图形学管线各阶段的职责。
- **合理假设**（未核实）：知道神经网络用梯度下降训练，知道损失函数的大致含义；不假设读过 NeRF 或任何辐射场论文。
- **当前卡点**：能说清"三维高斯投影后是椭圆"，但**说不清椭圆怎样变成像素颜色**。常见的两处断裂：一是以为"椭圆"本身就是渲染器使用的东西（实际使用的是逐像素权重）；二是以为协方差的某个近似版本只是"稍微不准"，不知道它会让整个像素覆盖范围错掉。
- **本次目标/期望深度**：走通"高斯参数 → 协方差 → 屏幕协方差 → 每像素权重 → 混合成颜色"（主线）→ 推导雅可比与线性化边界（深入）→ 知道训练与排序为什么这样设计（工程）。
- **应省略或只链接的基础**：不再讲投影矩阵来源、不再讲重心坐标定义、不复述梯度下降。

## Cognitive Gap · 核心认知转折

- **一个真实问题**：NeRF 沿相机射线查询隐式场并合成；3DGS 投影显式高斯后逐像素求权重。两者的计算路径不同；要理解后一条路径，必须回答：一个三维高斯在屏幕上到底贡献了什么？不据此推断未经同条件评测的速度高低。
- **原模型作出的错误预测**：投影得到一块椭圆，椭圆就是"这个高斯占据的区域"，区域内外的像素被填上颜色。
- **反例（可手算）**：横向 $0.01$、深度 $0.5$、中心 $(1,0,2)$ 的针状高斯，屏幕足迹的 $1\sigma$ 半轴是 $62.5\times2.5$ px。离中心 10 px 处，校正路径权重仍有 $0.987$，朴素路径却只剩 $0.000335$。**比较的是同一像素在两条协方差路径下的衰减权重，不能把差异归因于是否填充椭圆。**
- **Core Insight**：屏幕上的椭圆是协方差 $\Sigma'$ 的等值线，而渲染器逐像素求的是未归一化衰减核 $\alpha=o\cdot\exp(-\tfrac12\mathbf d^\top\Sigma'^{-1}\mathbf d)$。它既不是概率密度，也不是物质密度；这个权重场**没有边界、没有内外之分**。足迹半轴错 25 倍，就是函数的衰减尺度错 25 倍，进入颜色合成的权重随之算错。

## Minimal Understanding Loop · 最小理解闭环

- **先看到什么**：协方差的等值线与它对应的衰减权重场（同一 $\Sigma$ 两种画法）；紧接着是朴素与校正两条协方差在**同一像素**上给出的权重剖面——一条宽、一条窄成尖峰。
- **可以预测什么**：把深度尺度从 $0.5$ 降到 $0.01$，两条曲线会重合吗？把高斯移回光轴呢？离中心 10 px 处两条曲线各剩多少？
- **哪个结果暴露原模型不足**：光轴上两法**精确**相等（不是近似），因为雅可比第三列在那里恒为零——这说明错误被"中心取景"掩盖，而不是不存在。
- **新模型怎样解释**：$\pi(x,y,z)=(x/z,y/z)$ 的雅可比第三列含 $x/z^2$、$y/z^2$；展宽倍数 $\sqrt{1+(x/z)^2(\sigma_\text{along}/\sigma_\text{cross})^2}$ 只依赖两个无量纲量；该倍数直接决定 $\exp(-r^2/2)$ 的衰减尺度。
- **Transfer Check**：保持中心 $(0.5,0,2)$ 不变，把横向与深度尺度同时翻倍，预测轴比、半轴及近似精度如何变化；再把深度尺度拉到 $1.0$，判断公式是否还可信。（正文末节，两个都未直接演示）
- **自然退出点**：能解释"协方差错 → 权重错 → 颜色错"这条链，并能预测平移回光轴与改为各向同性时的不同结果。此时对排序、增密一无所知也不影响这个模型成立。

## Natural Narrative & Core Bridges · 自然叙事与核心跳步

- **一篇讲完，不拆篇**：两条渲染路径 → 高斯是什么 → 投影足迹 → **每像素权重** → 混合排序 → 参数从哪来 → 近似边界，是同一条因果链。
- **最不能跳过的三个环节**：
  1. **协方差 → 每像素权重**（修订后新增，初版完全缺失）。必须写出 $\alpha=o\cdot\exp(-\tfrac12\mathbf d^\top\Sigma'^{-1}\mathbf d)$，并给出同一像素上两条协方差的读数对比。缺了这一步，"椭圆"和"照片"之间没有桥。
  2. **雅可比第三列为什么会非零**——不是"深度被忽略"，而是近端张开角更大、远端更小，深度差异在屏幕上变成横向长度。用俯视图给几何解释，图中两个点的横向偏移必须真的相同。
  3. **排序为什么是正确性而不是优化**——透射率与顺序无关、颜色与顺序有关；图必须按近→远遍历，否则每个图元的权重都被乘错。
- **只供内部参考、不写入正文的读者背景**：上面 Learner State 的"确认已知"与"合理假设"两栏。
- **需要准确图示、可核算的机制**：协方差的等值线与衰减权重场、俯视图的深度到横向折算、特征分解得到的椭圆、**两条权重剖面**、前向 α 合成的透射率表、线性化失效的实测曲线。全部由 `src/math/gaussian-splatting.ts` 计算。
- **检查并删除的模板化内容**：没有"本节目标/现在你掌握了"；没有对读者水平的评判；没有为凑栏目而加的总结段；只有一个交互实验。

## Progressive Disclosure · 渐进深入

- **主路径**：两条渲染路径 → 高斯是衰减权重场而不是表面 → 投影不是仿射 → 雅可比第三列 → $\Sigma'$ 与椭圆半轴 → **每像素权重与马氏距离** → 两条剖面分家 → 25 倍反例作为支撑检查。
- **Derive / Implement**：$J$ 与 $\Sigma'=J\Sigma J^\top$ 的完整推导、无迹变换的替代方案、混合公式、损失函数与自适应增密/剪枝/不透明度重置、tile 级排序的实现取舍。
- **Transfer / Boundary**：光轴精确一致与各向同性离轴仍有误差、线性化在高深度尺度下的失效量化、静态场景、视角相关外观与透明表面的表示边界、与 NeRF 的分工、可编辑性通向资产化。
- **Pressure Risks**：不在同一页同时引入 SH 的球谐基定义与协方差参数化；矩阵符号只出现一次坐标约定说明；不复述投影矩阵。

## 媒介与验收

- **为什么用文字 + 静态图 + 一个交互**：协方差到权重的映射需要一条可读的剖面图；"参数变化如何影响读数与覆盖范围"确实需要交互，且界面与底层共用同一计算模块。
- **事实与数学依据**：投影协方差、混合公式、自适应增密与不透明度重置规则来自 Kerbl 等 2023（arXiv:2308.04079）。线性化失效曲线与权重剖面是本文的独立数值计算，不是对原论文实验的复述。
