# Learning Brief：线性代数的几何本质

这是课程级设计依据，覆盖现有原型和规划章节；不表示独立内容审核已完成。局部修复复用本稿，仅在主线改变时更新。

## 读者与问题

读者已掌握平面坐标、向量相加和数乘，但可能把矩阵当作数字表，把行列式当作长度倍率。切入备选：如何记录平面无数个点的变换；为什么二维区域会被压成一条线。首选前者，因为它直接引出线性性与基；后者用于检验信息丢失。

## 发现路径

记录逐点去向不可行 → 先把任意向量写成基的线性组合 → 保持加法与数乘的变换只需要记录基的像 → 用两列组织这些像，推导矩阵乘向量 → 比较单位方格变换前后的有向面积 → 退化揭示秩，保持直线方向引出特征向量，再讨论 SVD 和 PCA。

矩阵是线性映射在选定基下的表示，不等同于映射本身。先在固定标准基下推导，再在后续章节讨论换基；平移不满足 T(0)=0，不能混作二维线性变换。行列式符号表达定向，而非每个向量掉头。

## 媒介与检验

使用现有 MatrixTransformLab 原创 SVG，移动基向量以检验“列决定去向”，用退化、反射、旋转预设区分面积与长度。无需外部图片。正文必须独立解释线性性与有向面积，组件不能替代证明。

迁移题：两列相同但非零时，哪些向量映射到零？参考解释：T(x,y)=(x+y)c，零空间是 x+y=0 的直线；c 非零时像空间是一条线。
