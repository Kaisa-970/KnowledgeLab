# KnowledgeLab 图示与视觉素材使用规范

> 本文同时约束**事实检索**、**图片检索**、**是否可以复制或改作**、**自行绘制**、**质量验收**。
> “在网上找到一张好图”不等于“有权将它放进公开课程”。

## 1. 先写解释目标，不要先找图片

为每个候选图建立视觉任务（可写入 `docs/templates/visual-brief.md`）：

- **学习疑问**：该图要消除什么误解？
- **必须呈现**：哪些对象/方向/坐标/标注/时间步骤？
- **读者应能说出**：看完后能观察或预测什么？
- **合适媒介**：现有图、静态原创 SVG、代码绘图、序列图、真实照片、交互，或纯文字；
- **可核验事实**：数值、轴、比例、引用、误差范围；
- **验收**：一眼可读，手机清晰，有 alt/caption，结论与讲解一致。

无明确教学作用，不加图。对于抽象数学/算法的精确几何图，**原创可计算 SVG 往往比网络截图更适合**；对真实设备/论文特定结果，权威原始图片可能更适合。

## 2. 素材检索顺序（权威性 vs 使用授权）

**这是获取可信参考的优先次序，而不是复制许可的优先次序。**

1. **一手权威材料**：原论文与作者/机构项目页、官方标准/规范、官方文档、大学公开课、作者维护的示意图。优先核对事实、定义、适用条件和版本。
2. **高质量教学资源**：有明确作者与可追踪推导的公开教材、教学博客、Distill 风格解释、图形学/数学专业社区。用于对比不同讲法；不得把热门程度当成准确性。
3. **其他公开资源**：论坛、个人帖子、转载聚合；只能作为线索，关键结论应回溯原始出处。
4. **找不到合适或可合法复用的图**：根据已经核实的概念，用 SVG/Canvas/绘图代码**原创绘制**；必要时用可用的图像生成工具制作**非数值精确**的概念插图，并核查语义。

注意：即使在第一层找到完美的图片，只要授权不明，也应**使用链接作为参考，而不是将图片嵌入/下载进仓库**。也可能在检索后直接绘制原创图，因为教学更清晰、可编辑或更适合交互。

## 3. 可复用性判定（必须逐张判断）

每张外部图在加入仓库前，记录：

- 原作者、原始页面 URL、资源原始 URL（非二次转载）；
- 授权依据（明确许可证、来源许可、书面授权），授权是否包含复制/修改/公开网站展示；
- 许可证要求（署名、同方式共享、非商业限制、禁止改作等）；
- 需要的署名形式、修改说明、访问日期；
- 是否含人物、敏感内容、商标、隐私或特殊限制；
- 是否允许下载并本地托管。不要默认允许盗链或批量抓取。

常见规则：
- **无明确授权 ≠ 免费可用**。公共网页的访问权不等于图片再发布权。
- **引用原链接 ≠ 自动获得复制权**；加署名也不能弥补无授权。
- 明确允许的公共领域、CC0、满足条件的 CC BY 等可纳入，但要遵守条款；CC BY-SA、NC、ND 等存在额外限制，不满足时不要嵌入或改作。
- **原创重画必须是真正独立设计**，可以借鉴公共知识、数学事实和通用可视化思想，不要照着受限图形描摹复制独特表达。
- 不把外部站点图片热链作为默认方案；优先本地管理可合法使用的资源并稳定归档来源。
- 授权不清时：使用外部链接说明出处；或基于事实独立绘制新图；仍不确定时请求人工审查。

不要把“合理使用”当成自动许可，跨法域争议要谨慎；高风险素材交由维护者决定。

## 4. 自制图的工具顺序

- **首选程序化矢量图（SVG）**：向量、坐标轴、曲线、网络、张量形状、算法流程；可重算、可缩放、可测试。
- **可复现绘图脚本**：Python/Matplotlib、JS/Canvas、D3 等，适于真实数据或大量重复采样；记录数据来源、随机种子和参数。
- **分步骤的原理图**：流程、状态、时序；优先简单的 SVG/Mermaid/React 组件，确保文字与方向正确。
- **Three.js/WebGL**：三维旋转、遮挡或真实空间关系确实不可用二维说清时使用。
- **图像生成工具**：仅当真实感/创意比几何精确更重要时，如概念场景背景；**不要用于精确坐标、公式、线路图、真实论文结果、带数字刻度的曲线**。模型生成图必须检查虚构细节和误导风险。

无论工具是什么，**“是否需要交互”由认知问题决定，不由工具可用性决定**。

## 5. 推荐的素材文件和出处记录

- 通过审查的素材建议放 `public/assets/<course-id>/`；原创 TSX/SVG 可以放 `src/components`。
- 每幅图须记录 `docs/templates/visual-brief.md` 的字段（或同等信息），若发生复制/改作则必须写明来源和许可证。未来可迁入 JSON manifest；**当前没有自动版权扫描器**。
- 在课程中提供准确 caption 和 alt；图为原理示意必须标“示意”，不能暗示真实数据/真实设备照片。
- 不使用没有明确权利的截图、论文整页、受限视频帧，不能依赖“教学用途”自动免责。

## 6. 验收清单

- [ ] 教学问题和这张图的“必须出现的信息”明确？
- [ ] 参考事实核验到一手来源？没有时已标注不确定性？
- [ ] 若使用外部图片，权利依据、署名、改作条件可追溯？
- [ ] 若为原创图，未抄袭受限视觉作品，数学/尺度/方向正确？
- [ ] 标签、轴、单位和状态清晰；配色非唯一表达方式？
- [ ] 图片手机可读，并配适当的 alt、caption 或详细文字解释？
- [ ] 不把不存在的工具使用、网络查询、下载授权或图像审核说成已完成？

## 7. 禁止行为

不将网络搜索缩略图直接当生产素材；不伪造作者和许可证；不挪用 watermark 图片并裁切水印；不生成假造的论文实验截图；不因为缺图而降低论证的准确性。
