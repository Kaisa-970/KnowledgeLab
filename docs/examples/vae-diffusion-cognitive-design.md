# Cognitive Design 示例：VAE 与 Diffusion 为什么生成路径不同？

> **课程设计样例，尚未制作课程、模型实验或学习者验证。** 不把复杂生成模型过度简化为这两个算法的唯一实现。
> 非识别性读者假设：知道神经网络、编码器/解码器、简单概率分布和梯度训练，但可能不清楚生成与重建的区别。

## Learner State / 目标

- **假设已经会**：网络输入输出、损失函数、训练/推理、采样随机数的基础；
- **需要澄清**：为什么 VAE 的重建路径常通过编码器，而 Diffusion 的生成路径却常从噪声反复去噪；“模型学什么”与“推理做什么”是否被混成一回事；
- **本次目标**：先准确区分两种**生成机制**，再自愿进入 ELBO/噪声预测目标的数学推导；
- **不要做**：上来重新讲完整 Transformer、梯度下降、GAN 历史或所有生成模型分类。

## 一张不依赖大段定义的对照

有一张真实的猫图像。训练后让模型**不再看到这张图，独立生成另一张猫图**，两类模型怎么做？

| 问题 | VAE（经典标准形态） | DDPM 式 Diffusion（经典离散步骤） |
| --- | --- | --- |
| 生成从哪出发？ | `z∼p(z)`，从先验采样潜变量 | `x_T∼N(0,I)`，从噪声采样 |
| 生成时主要重复什么？ | 解码器通常一次映射/一次概率采样 | 反复估计去噪的转移，逐步生成 `x_{t-1}` |
| 训练时主要学什么？ | 学能重建图像、同时把后验与先验约束接近的潜空间及解码器 | 训练逆向去噪模型；典型实现通过预测噪声或相关参数化 |
| 能否单凭一个图的重建流程代表完整生成？ | 不能，**编码真实图像**与**从先验生成**是两条路线 | 不能，**训练时的加噪**与**推理时的逆向去噪**要区分 |

这张表是**教学简化，不是所有 VAE/Diffusion 变体的排他描述**。后者可能用潜空间 Diffusion、不同参数化和采样器，不能因此声称 Diffusion 必然在像素空间或必须固定步数。

## Minimal Loop：先看运行路径

1. **预测**：VAE 推理生成一张新图时，是否一定需要先有一张真实图经过 Encoder？
2. **冲突**：不需要。真实图 → Encoder → 潜变量 → Decoder 是重建/推断路径；`z∼p(z) → Decoder → 新样本` 才是典型无条件生成路径。
3. **建立新模型**：VAE 主要学习可采样潜空间中的概率建模与解码生成；DDPM 式 Diffusion 则学习逐步逆转噪声过程的条件分布。
4. **迁移**：如果把 DDPM 的去噪网络训练好，再把反向过程换成另一个采样器，改变的是哪部分？回答：主要改变**采样过程/数值路径**；是否保持质量、分布和理论保证要看采样器与模型条件，不能直接保证完全等价。

一幅**训练/推理双通路小图**比两页泛泛的 VAE、Diffusion 定义更有用；课程开头不需要完整 ELBO 推导，也不应强制生成效果图。如果要画精确架构或张量，要根据原始论文/实现核对。

## Progressive Disclosure 与退出点

- **主路径**：两种从随机数生成的不同运行链；训练与生成/重建不混淆；完成一次反例预测就可暂停。
- **原理路径**：VAE 为什么需要 KL 与重建项，ELBO 的近似推理意义；DDPM 正向过程/逆向模型及噪声预测损失为什么合理。逐个处理，**不要同屏堆 ELBO、Markov 链和 Score Matching**。
- **边界路径**：两者可以组合（潜空间先由 Autoencoder 压缩，再做 Diffusion）；质量、速度和表达能力需依具体架构/实验比较，不凭范式断言优劣。

## 认知压力风险

`posterior/prior`、`ELBO`、`q(x_t|x_0)`、`ε_θ` 若在一屏同时出现，会造成概率符号切换成本。先用**真实图是否参与推理**和**生成是否逐步迭代**两个可回答的问题，让学习者知道每个数学量为什么需要。

**未验证事项**：尚无实际课程、独立数学审稿和学习者答题证据。本设计不能声明学习者已理解 VAE/Diffusion，也不能证明哪种开场最吸引人。
