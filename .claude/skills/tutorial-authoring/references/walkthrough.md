# Walkthrough：一篇 8.5/10 的文章是怎么改出来的

这份文档不是成品赏析，而是**制作过程的还原**。已定位的改稿证据锚定在真实提交上，可以用 `git show <hash>` 复核。

对象是 `src/content/lessons/generative-from-noise-to-image.mdx`，真实读者评分轨迹 **2 → 5 → 7.5 → 8.5**。

**为什么需要它**：`docs/TEACHING_STYLE_BASELINE.md` 记录了 8.5 分那篇"应当保留的做法"，但那些是**结论**。结论无法教另一个 Agent 怎么在**尚未写出好文章时**做判断。这份文档记录的是决策、被否决的版本、以及每次修改的依据。

---

## 一、轨迹与证据

| 版本 | 提交 | 实际改动 | 反馈 |
|---|---|---|---|
| v1 | `fee4004` → 早期 | 按概念分节，几乎没有关键图 | **2/10**（问题引入薄弱，像教科书） |
| v2 | · | 分章节配图 | **5/10**（有进步，但割裂、文案模板化） |
| v3 | `577eaf8` | **五篇合并为一篇**连贯长文（+262 行） | **7.5/10**（连续性好了，但重点不突出、机制跳步） |
| v4 | `5ba3c9b` | **补上缺失的因果桥梁**（+117/−112） | **8.5/10** |

从版本变化得到的观察（不是控制变量实验）：

1. **2→5 靠加图，收益有限**。v2 的图没有改变"割裂"这件事，因为它把五篇各自配了图，等于把同一个问题重复了五遍。
2. **5→7.5 靠合篇，收益很大**。这一步没有增加任何新知识，只是把五页并成一页。
3. **7.5→8.5 的改动重点是补桥梁**。这一步也没有新增课程、交互或图片数量。

## 二、7.5 → 8.5 那一步：到底补了什么

`5ba3c9b` 的提交信息是 **"explain the missing bridges from noise prediction to reverse kernels and conditional flow"**。学习者 7.5 分的原话记录在 `learning-brief.md`：

> 新的长文比上个版本更自然（7.5/10），但**核心原理仍不够容易理解，重点不够突出**。用户标记了"你知道神经网络是怎样训练的"等直接评判读者基础的文字。

注意这两句是分开的：**"不够容易理解"和"文案有问题"是两件事**，而且前者更严重。实际改动也分成完全不同的两类。

### 改动类型 A：新增四座桥（直接补充机制解释）

对照 `git show 5ba3c9b`，新增的是**具体的因果问答对**，不是新的知识点：

| 桥 | 原文缺什么 | 补上的形式 |
|---|---|---|
| 噪声预测为何是**条件均值** | 只说"MSE 最优预测是条件期望"，没解释为什么 | 用 0.4 的双解例子：$x_0=2,\epsilon=-1$ 与 $x_0=-2,\epsilon=2$ 给出**同一个** $x_t$，所以输入无法唯一决定标签 |
| 条件均值为何**联系到 score** | 直接给出 $\nabla\log p_t=-\mathbb E[\epsilon]/\sigma_t$ | 先给一维双峰的几何直觉（峰左侧的观测，其成因噪声偏负），再给严格等式 |
| 局部预测**怎样变成一步反向转移** | 知道 score 后直接跳到采样 | 明确 $\hat x_0$（干净估计）与 $x_{t-1}$（真正算出的下一步）**不是同一个东西**，并说明高噪声时一次估计不足以表达不确定性 |
| 一步转移**为何保证整批分布** | 只讲单个样本走对了 | 写出 $p_{t-1}(y)=\int p(x_{t-1}=y\mid x_t=x)p_t(x)\,dx$，说明"一次转移管局部，积分后得到整批样本的新分布" |

**可迁移的形状**：每一座桥都是同一个句式——

> **读者会自然问的下一个问题是什么？正文在那个位置有没有正面回答？**

四座桥的位置分别是：给出损失之后（"凭什么是条件均值"）、给出 score 之后（"凭什么和噪声预测有关"）、给出采样之后（"凭什么这一步能生成"）、给出单样本轨迹之后（"凭什么整批分布对"）。

### 改动类型 B：删掉评判读者的文字（改善阅读表达）

删掉的原文（见 v3 稿）：

> 你知道神经网络是怎样训练的，也知道一幅图像在计算机里无非是一大组数字。所以我们不必从梯度下降、张量或正态分布的定义重新讲起。

删掉的还有若干"到这里，你可能会发现一个漏洞""这句话可能还有些抽象。没关系，我们就从……"。

**这两个类型的收益不同**：A 补足机制依据，B 改善表达。它们在同一版本中共同改变，不能用总评分分离各自效果，也不能据评分断言读者已理解每个环节。把两者混为一谈会导致错误的优先级——先去润色语句，机制仍然跳步。

### 改动类型 C：把"看起来对"的图换成"算得出来"的图

`visual-brief.md` 的对应改动写得很具体：

- `DiffusionSamplingFigure`：从"逐渐清晰的数字图案"（暗示这是一段去噪录像）换成**三幅按明确高斯加噪公式计算的分布曲线**。并加了一句限定：**"它展示的是边缘分布，绝不是一张图逐步去噪的实际录像"**。
- `FlowPathsFigure`：右图从"定性解释"换成 $z\sim\mathcal N(0,1)$ 到 $x\sim\mathcal N(1,0.5^2)$ 独立配对的**解析高斯平均速度场 ODE 解**。
- 并补上数据依据：共享 `src/math/generative.ts` 的 `diffusionBridgeDensity`、`gaussianBridgePosition`、`gaussianBridgeVelocity`，单测检验分布归一化、二阶矩、终端混合与"轨迹满足 ODE"。

原话很关键：**"避免图画得顺眼却描述了错误的数学过程。"**

## 三、5 → 7.5 那一步：为什么合篇幅度最大

`577eaf8` 把五个页面（training、sampling、flow-matching、noise-to-distribution、not-averaging）合并为一篇。`course-review.md` 记录的判断是：

> 五个独立页面让一条知识因果链割裂，文案仍像课程模板。

**代价一：切一次页，读者要重建一次上下文。** 五页里每一页都要重新交代"我们刚才在讲什么"，这些重复不是冗余，是**割裂本身的成本**。

**代价二：分页会诱导"每页都要有个结论"。** 这正是"文案像模板"的来源——每页开头"本节目标"、结尾"你现在掌握了"。合篇之后这些结构无处安放，自然消失。

**判断规则**（现在写进了 `SKILL.md`）：Track / Module / Course / Concept 是**知识组织层级**，不等于网页篇数。只有先修条件、任务目标或题材边界确实不同才拆篇。

## 四、被否决的版本，以及否决的理由

这一节是这份文档最有价值的部分——**知道什么被否了、为什么否**，比知道什么被留下了更有指导力。

| 被否决的做法 | 出现在 | 否决理由 | 正确的替代 |
|---|---|---|---|
| 五个独立页面 | v2 | 因果链割裂，且逼出模板化文案 | 合为一篇连续文章 |
| "你知道……""你已经学过……" | v3 | 直接评判读者水平 | 内部据此裁剪深度，正文不作声明 |
| 每节"目标/掌握/下一节" | v2–v3 | 教学模板冒充对话感 | 自然因果过渡 |
| "逐渐清晰的数字图案"作为去噪示意 | v3 | **图画得顺眼，但描述的过程是错的** | 换成按公式计算的边缘分布曲线，并注明"不是去噪录像" |
| 定性手绘的 FM 轨迹 | v3 | 无法核验 | 解析高斯 ODE 解 |
| 为凑第六张图复用车文本型卡片 | v3 | 图的数量不是指标 | 删掉，改用紧凑文字 |
| 把"平均"理解为"糊在一起" | v3 | 对条件平均的常见误读 | 明确"这是每个位置各自的平均" |
| 把"随机采样 vs 确定性采样"当作 Diffusion/FM 的分类 | v3 | 分类不成立 | 分开看三个选择：分布路径、网络目标、求解方法 |

## 五、可复用的判断清单

从这次演化里提炼出的、**在写作当下就能用的判断**：

1. **写完一个关键结论，立刻问：读者在这一点上会追问什么？** 检查正文是否在需要的位置提供依据；不要求紧接的下一段必须回答。
2. **分清"机制问题"和"文案问题"**。先修关键机制缺口，同时保留自然清晰的表达。
3. **每次想拆篇时，先问：这两部分真的有不同的先修或任务边界吗？** 只是"内容多"不是理由。
4. **每张图问一句：这张图画的是真实计算出来的量，还是我为了说明而画的示意？** 如果是后者，必须显著标注，且不能让它暗示一个错误的过程。
5. **图的数量、交互的数量、测试的数量都不是指标。** `577eaf8` 和 `5ba3c9b` 都没有增加这些。

## 六、这份文档不能替代什么

- **不能替代真实读者的评分**。轨迹里 2→5→7.5→8.5 的每一档都来自同一位学习者的实际阅读。没有新反馈时标记理解未验证；审核状态仍按 `docs/CONTENT_CONTRACTS.md`，不能把一次试读评分新增为机器发布门槛。
- **不能替代独立数学审查**。本次核对的是"当时改了什么"，不是"那些公式都正确"。
- **不能保证迁移**。这套经验来自生成模型题材。线性代数、Vulkan、机器人学习是否同构，尚无证据；`docs/TEACHING_STYLE_BASELINE.md` 也明确说基线应继续迭代。

实际制作时使用 [局部讲解示范](explanation-workshop.md)：其中两种领域的跳步原稿、补充证据、媒介选择和未展示变式，把历史取舍转换为可执行方法。示范尚未获得真实试读反馈。
