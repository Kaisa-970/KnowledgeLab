# Learning Brief：傅里叶分析——从叠加到拆分

这是课程级重构设计稿，承接原 docs/examples/fourier-learning-brief.md。现有 MDX 尚未按本稿重写，数学内容审核未通过；课程保留 prototype。

## 读者与问题

读者已掌握三角函数、弧度与定积分。切入备选：同音高乐器为什么音色不同；光滑正弦叠加为什么能逼近有跳变的方波。首选后者作为可计算模型，音色作为应用连接；真实声音还含瞬态、包络、噪声及非谐波成分，不能用理想周期模型解释全部音色。

## 发现路径

一条正弦不够 → 增加频率分量看见形状变化 → 叠加容易，如何反向拆分 → 用乘积积分定义内积，正交性使系数可被单独提取 → 区分常数函数的归一化，推导方波系数 → 奇偶性减少候选项 → 跳点中值与邻域过冲迫使我们区分逐点、均方、一致收敛 → 从任意周期把序号映射为物理频率，再连接频谱与非周期信号。

先用有限部分和说明投影，不未经条件说明就交换无穷求和与积分。常数函数平方积分为 2π，正弦零频函数恒为零；正整数频率的正交公式不能无条件套到 n=0。

## 媒介与检验

复用 FourierSeriesLab 原创曲线和数值模块。需要比较谐波开关、跳变邻域放大、误差定义；无需外部音频或图片。残差必须说明采样与剔除区间，离散 RMS、连续 L² 和单点误差不是同一指标。

迁移题：方波向上平移 2 后哪些系数改变？参考解释：平均值 a₀/2 变为 2，正整数频率的系数不变；常数与这些函数正交。

## 已知内容问题与后续复核

现有正文仍把正交式写为 m,n≥0，混淆单点误差与 RMS，并声称未剔除跳变邻域的 RMS 不收敛；这些不能由通过数值测试证明。自测平移 2 的答案又写成平移 1。后续重构须逐项修正文稿并独立核验，含奇次谐波积分的符号解释、Gibbs 端点与误差条件。本轮只记录阻塞，不宣称课程内容已修复。
