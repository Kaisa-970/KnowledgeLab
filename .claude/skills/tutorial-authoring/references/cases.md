# 已通过学习者反馈的案例，以及一篇失败案例

这里不把“8.5 分文章”当写作提示词，也不把“6 分文章”当要规避的词汇表。比较它们在**问题选择、论证链和视觉语义**上发生了什么。

## 正向基准：生成模型长文（实际读者 8.5/10）

- 文章：\`src/content/lessons/generative-from-noise-to-image.mdx\`
- 图：\`src/components/GenerativePrincipleFigures.tsx\`
- 源数学：\`src/math/generative.ts\`
- 固定提交：\`b886a5ea6f19c95eb1edcb6b23d0f965b03bb3ed\`
- 演化反馈：2 → 5 → 7.5 → 8.5，详见 \`src/content/courses/generative-models/course-review.md\`。

**为什么后来明显改善？** 第一版只是按概念讲，第二版虽然加图却仍分篇、公式跳步。8.5 版真正解释了如下机制：

\`\`\`text
已知加噪标签 → MSE 的条件平均预测
  → 为什么预测有分布局部信息（score）
  → 为什么这种信息能代入反向均值/反向条件转移
  → 多步反向转移怎样推动整批样本的概率分布
\`\`\`

下一段由前一段尚未解决的难题引出，插图是实际方程或分布变化的证据；图像不假装为训练网络输出。Flow Matching 段同样把**训练时的条件路径**与**生成时的平均速度场**分开讲。

**可迁移的不变量**：找“还差哪一步才能真正解释”的因果桥梁、对它给证据、读者无需跨多个页面跳转。**不可机械迁移**：Diffusion 的问题句型、五个标题、图的数量、具体类比、公式序列。

## 反向基准：3DGS 投影长文（实际读者 6/10）

- 文章：\`src/content/lessons/gaussian-splatting-projection.mdx\`
- 图：\`src/components/GaussianSplattingFigures.tsx\`
- 源数学：\`src/math/gaussian-splatting.ts\`
- 审稿报告：\`src/content/courses/gaussian-splatting/course-review.md\`
- 提交：\`e57be6f9ee3426a044f4c9353caf28429cd1c2f0\`

**并不是规范完全失效**：作者没有按定义目录写，也做了单篇、真实数值、Jacobian 推导、测试和课程知识归属；但读者仍给了 6 分。

**三种应当主动发现的失败：**

1. **错误的中心**：高光时刻变成“忽略深度导致 25 倍足迹差异”。这是好反例，却夺走了应该用来回答“高斯投影机制/形成像素”的篇幅。对用户提出的局部问题（为什么投影为二维椭圆），首先应清楚交代“3D 高斯作为概率/空间形状 → 局部投影映射 → 二维协方差/椭圆”，再按范围决定是否延伸到像素权重和合成。不把所有 3DGS 话题硬塞进去。
2. **真正的桥梁被压缩**：在声称要解释“椭球怎样拼出照片”的全文里，“二维协方差 → 具体像素处的 Gaussian 权重 → 有序 Alpha 合成”连接不足。数学上漂亮的投影反例并没有代替 rasterizer 的机制说明。如果标题只问投影，便应缩小承诺范围；若标题覆盖照片，必须完成像素链。
3. **图示语义错误没有被测试发现**：\`SplatBlendingFigure\` 的前向透射累积按“远→近”排列，却将这一顺序当作 front-to-back 合成；应按“近→远”遍历，否则每个 splat 的颜色权重变了。CI 的 106 单测/94 浏览器检查通过不意味着这张图语义正确。部分 SVG 文字/虚线的缩放语义也需要实际截图检查。

**自检方式**：把正/负两篇的标题和 Learning Brief 暂时遮住，只依据文章内的图和文字回答：
- 作者最想解释的核心过程是什么？读者读完能否真正从输入预测中间状态与输出？
- 最长的段落在回答主问题，还是在展示一个易计算的边界反例？
- 拿掉小标题和作者自评，机制仍完整吗？
- 图的顺序、符号、数据来源能经独立核实吗？
- 删掉非核心实验/长证明后是否反而更好懂？

## 对两篇的处理原则

不要宣称这是一份严格训练数据集，也不把分数当成自动通过阈值。它是当前同一真实读者反馈下的**对照校准集**，用来提醒 Agent 避免“表面完整 → 实质偏题”的陷阱。以后加入 PCA、Vulkan、机器人等不同学科的真实反馈，才能逐渐验证跨领域泛化。
