## 本轮改进范围

| 单元 | 新的教学起点 | 验收任务 |
| --- | --- | --- |
| `why-frequency` | 为什么播放器能调低高频？立即试听与关掉 660 Hz 成分 | 同步观察时域波形与频域柱形；知道幅度谱不等于完整信号 |
| `frequency-projection` | 只有复杂曲线，如何找回未知配方 | 从含常数、正弦和余弦的混合函数取出系数 |
| `square-wave-synthesis` | 已有计算工具，为什么过冲依旧 | 平移、对称性与删除系数后的均方误差 |

### 新图示、交互与权利

- 独立程序生成 `FrequencyLensFigure`，不含外部授权图片；曲线严格由同一个数学函数计算。
- `FourierSeriesLab` 将观察区域跟随真实的跳变/折角，并分段绘制目标函数，不把跳变画成连线。
- 既有核心数学模块、数学 oracle 与 E2E 检查继续作为自动化验证依据。

## 验证边界

本分支使用 GitHub Actions 执行课程校验、类型检查、数学单测、生产构建、桌面及移动端 Playwright。**实际结果以本 PR 的 CI 记录为准；该报告不预先声明测试已通过，也不虚构本地浏览器截图。**

独立审稿仍须核查 LTI 的准确适用范围、有限投影与无穷极限的区别、Dirichlet/Parseval 的前提、峰值推导的准确性、移动端视觉清晰度和知识连接是否自然。尤其要邀请学习者实际阅读第一节，判断其学习动机是否真实。当前尚不能升级 reviewed。

## 根据首次体验反馈的改进

用户认为上一版例子不够直观、文字偏多。本轮不继续扩充知识，而是让首页由可试听/可拖动的 220 Hz + 660 Hz 信号实验引导；数学模型、物理单位和 LTI 机制放进折叠区域。第二节把正交性计算与最小二乘配方的证明放进折叠区域，第三节把 Gibbs 1.179 峰高推导折叠，保留严谨推导的可访问性。尚待真实学习者重新试读，不能因这次修改直接宣布体验达到目标。
