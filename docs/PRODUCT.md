# KnowledgeLab — 产品定义

## 愿景

输入学习需求，输出结构化、可操作、可解释、可验证的交互课程。KnowledgeLab 应连接不同领域的知识，使学习者不仅能“记住是什么”，也能“看到如何变化、理解为什么、自己验证”。

## 第一原则

1. **交互即论证的一部分**：动画与滑块都必须回答具体问题。
2. **直觉与深度并存**：先构造心智模型，再说明严格数学或运行机制。
3. **学习者主动探索**：鼓励猜测、操纵、对比、找反例，不只是点击下一页。
4. **跨领域知识网络**：比如矩阵变换 → SVD → PCA → 点云法线；梯度下降 → 反向传播 → 深度学习；图形管线 → GPU 并行 → 3DGS。
5. **Agent 是生产工具，不是正确性的担保**：内容要经过检查，未来以课程计划、产物、测试和审核记录形成可追溯链路。

## 人群与边界

起步阶段面向具备基础编程能力、想系统建立数学/图形学/AI 底层理解的学习者。课程默认中文，可保留标准英文术语及公式。

**第一版不做**：社区、排名、付费系统、全自动无审核上线、自动抓取受版权保护教材、复杂课程编辑器或完整 LMS。

## 体验目标

一节高质量课程必须让用户完成：
- 提出一个可检验的问题；
- 操作 1 个以上与核心概念相关的实验；
- 用自己的话解释“输入变化 → 中间机制 → 输出变化”；
- 能理解核心公式或代码；
- 发现一个边界或反例；
- 知道这个知识在整个领域中处于何处。

课程数量、交互动画数量和 token 消耗均不能替代理解效果。

## Agent 形态

长期目标：学习需求 → 课程规划 → 内容和组件生成 → 正确性检测 → 交互/视觉检查 → 人工审核 → 发布；支持用户指定章节的局部修改。当前阶段尚未实现 Agent 服务，只建立兼容未来 Agent 的规范和示例。
