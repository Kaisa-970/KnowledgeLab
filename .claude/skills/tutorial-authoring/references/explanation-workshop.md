这是制作方法的示范，不是新课程、已通过试读的课文或固定正文模板。用于 Gate B：先检验一个关键连接，再扩展全文。下面的数值可独立复算；尚无学习者对这些示范的理解反馈。

## 数学机制：为什么协方差左右各乘一次变换

**跳步原稿**：“局部投影的导数是 J，于是屏幕协方差为 JΣJᵀ。”

原稿给出了答案，但没有说明 J 作用于什么，也没有解释第二个 J 的来源。此处不用补整章矩阵知识；只需让空间偏移如何改变散布变得可见。

**先写一个能够计算的情况。** 四个等权、中心为零的偏移是 (1,0)、(-1,0)、(0,2)、(0,-2)。使用总体协方差，即除以 4，得到 Σ=diag(0.5,2)。变换 A=diag(2,3) 后，偏移成为 (2,0)、(-2,0)、(0,6)、(0,-6)，直接重算得到 diag(2,18)。横向距离变成两倍，平方偏移变成四倍；纵向距离变成三倍，平方偏移变成九倍。

**将这段变成解释。** 协方差记录中心附近偏移的乘积平均：Σ=E[δxδxᵀ]。变换先作用于每一个偏移 δp=Aδx，而不是先作用于协方差。因此

```text
E[δpδpᵀ] = E[(Aδx)(Aδx)ᵀ]
          = E[AδxδxᵀAᵀ]
          = A E[δxδxᵀ] Aᵀ = AΣAᵀ。
```

左右各乘一次来自偏移及其转置各被变换一次。A 可以是 2×3，Σ 为 3×3，结果为 2×2。相机投影在中心附近满足 δp≈Jδx，所以使用同一规则得到 Σ′≈JΣJᵀ；近似号来自投影线性化，协方差的线性变换规则本身是精确的。

**图怎么选。** 若读者难以对应点与矩阵，画同一组四个点的变换前后对照，保持点身份和中心一致，标出两条尺度。若上述数字已经够清楚，不增加图或滑块。

**未展示的检验。** 横向改成压缩一半、纵向不变，Σ 如何变化？答案是 diag(0.125,2)，不是 diag(0.25,2)。依据是平方偏移变成四分之一。技术核验同时比较直接变换点再重算与 AΣAᵀ；不要只重复调用公式函数。

**停止条件。** 若试读者只能记住“两边都乘”，却说不出为什么，回到偏移乘积这一步修稿；此时不写增密、训练损失或其他外围内容。审稿者能给出答案只表明解释有依据，不表明读者已经理解。

## 程序机制：局部变量为什么有时不能再被闭包访问

**跳步原稿**：“闭包捕获变量，返回后仍可访问。”

这句话无法解释两个对象是否共享状态。比起扩写一整章作用域定义，先追踪一段小程序：

```js
function counter() {
  let n = 0
  return () => ++n
}
const a = counter()
const b = counter()
console.log(a(), a(), b()) // 1, 2, 1
```

两次 counter 调用各建立一个独立的绑定 n；返回的函数保留对各自绑定的访问。a 的两次调用读写同一个绑定，b 读写另一份。counter 的调用结束并不意味着仍可达的绑定必须消失。这说明的是语言行为；不把“栈帧一直留在栈上”当作所有引擎的实现事实。

**需要图时**画两个环境及函数到各自 n 的连接，用三次调用标出状态 0→1→2 与 0→1；没有必要制作等距机器比喻。

**未展示的检验。** 将 `const b = counter()` 改为 `const b = a`，输出变成 1,2,3。因为 b 与 a 引用同一个函数，访问同一个绑定。用真实 JavaScript 执行验证输出，读者需解释共享发生在哪一步，不能只猜输出。

这是“偏移如何变换”以外的另一种机制：状态身份与执行时序。不要把数学示范的图、公式或句型搬过来。
