# Visual Brief：3D Gaussian Splatting 的原理图

组件源文件：`src/components/GaussianSplattingFigures.tsx`；实验组件：`src/components/GaussianProjectionLab.tsx`；共享计算：`src/math/gaussian-splatting.ts`（配套单元测试 `src/math/gaussian-splatting.test.ts`）。

全部图为**原创 SVG**，无外部素材，因此不涉及第三方图片许可。数值全部由上述数学模块计算，图与测试共用同一套函数；正文中出现的每个数字都可在测试或该模块的返回值中复现。

> **历史记录（2026-10-14）**：初版有七张图，其中 `SplatBlendingFigure` 的遍历顺序与其声明的前向合成相反（权重被乘错，却因总数不变而未被发现），`PerspectiveDivideFigure` 的几何把世界点画在了成像平面之前。当时新增两张图、重画一张并逐张打开截图复核。后续 2026-10-23 的当前状态与截图检查记录见 `course-review.md`。

## 1. `SplatPipelineFigure` — 两条运行链

- **学习问题**：训练与渲染共用什么、各自更新什么？
- **呈现形式**：结构图（HTML 列表 + 容器样式，无 SVG）
- **必须包含**：训练侧（多视角照片与位姿 → 可微光栅化与损失 → 反向传播参数 → 自适应增密剪枝）；渲染侧（冻结参数 → 剔除 → 逐 tile 排序 → 前向合成）
- **事实依据**：Kerbl 等 2023 原文的训练与渲染流程
- **数学检查**：无数值断言，仅流程顺序；与实验组件、正文描述一致

## 2. `GaussianLevelSetFigure` — 高斯衰减权重场与等值线

- **学习问题**：三维高斯到底是什么形状？"椭球"是不是它的边界？
- **预期观察**：左图同一协方差的两条等值线（σ=1 青色填充、σ=2 外圈）；右图同一 Σ 对应的未归一化衰减权重场
- **呈现形式**：原创 SVG，两个同级 `<svg>` 共用 viewBox（±0.5）
- **图中对象与单位**：右图的格子由 `mahalanobisSquared` 逐点求值，160×160 网格，仅绘出权重 ≥ 0.05 的格子；画框和阈值只限制显示，未绘出的尾部仍非零
- **数学检查**：格子密度必须能分辨短半轴（约占视宽的 9%）；用 46×46 网格时短轴只有两格，看起来是方块而非高斯，已提高到 160
- **Caption 声明**：解析计算；明确显示阈值不是高斯边界，并说明"没有内外之分"，为逐像素求值做前置
- **Alt**：左为椭圆与两条等值线，右为同一协方差对应的衰减权重场

## 3. `SplatParameterFigure` — 参数清单

- **学习问题**：一个高斯携带多少个可学参数、各自作用是什么？
- **呈现形式**：HTML 表格（无 SVG）
- **事实依据**：3 位置 + 3 尺度 + 4 旋转 + 1 不透明度 + 48 球谐 = 59；原文 SH 取 3 阶
- **数学检查**：维数按原文明列；强调尺度是标准差而非方差

## 4. `PerspectiveDivideFigure` — 为什么近处的更靠外

- **学习问题**：为什么深度的展开会变成屏幕上的横向长度？
- **预期观察**：两个横向偏移**相同**（$x=0.60$）而深度不同的点，射线穿过成像平面时交点高度不同，$u=0.30$ 与 $u=0.20$
- **呈现形式**：原创 SVG 俯视图
- **图中对象与单位**：相机在左（世界 $z=0$），成像平面在 $z=1$，两个点在 $z=2$ 与 $z=3$（**在平面之后**，符合近平面成像），$x$ 向上为横向偏移
- **事实与精度依据**：投影关系 $u=x/z$；射线与平面的交点由 $x/z$ 直接给出，图与公式是同一个数
- **数学检查**：`the ray through a point meets the image plane exactly at x/z` 断言交点、$x/z$ 与 `projectPoint` 三者一致，并断言两个投影之比等于深度比
- **本轮修正**：初版把世界点画在成像平面之前、射线方向相反，纵向标度还把点推出画布；现按相机在左、点在平面之后重绘
- **Alt**：描述两个点位于平面后方、近者投影更靠外
- **边界**：概念示意，不是渲染结果截图

## 5. `FootprintAxesFigure` — 到达屏幕的协方差

- **学习问题**：足迹的大小与朝向由什么决定？
- **预期观察**：一个 $1\sigma$ 半轴约为 $62.5\times2.5$ px 的横向椭圆（轴比 25；等值线不是硬边界）
- **呈现形式**：原创 SVG，viewBox 收窄，caption 标明横向放大约 1220 倍
- **事实依据**：`ellipseAxes(projectedCovariance(...))`
- **数学检查**：半轴 = 特征值平方根
- **本轮修正**：删去 σ=2 等值线（在此轴比下超出画框、变成一块杂乱的灰椭），σ₁ 标签移入画框内
- **Caption 声明**：解析数据，说明放大倍数与"不是屏幕截图"

## 6. `PixelWeightFigure` — 光栅化器真正读的是每个像素的权重（本轮新增，全篇枢纽）

- **学习问题**：协方差怎样变成每个像素的不透明度？
- **预期观察**：两条 $\alpha(r)$ 剖面在中心都是 1，但衰减尺度差 25 倍；10 px 处校正路径给 0.987，朴素路径给 0.000335
- **呈现形式**：原创 SVG 折线剖面，横轴 −90…+90 px，纵轴不透明度
- **数据来源**：`gaussianFalloff`，与 `mahalanobisSquared` 是同一次计算
- **数学检查**：`the weight profile is what makes the naive footprint visibly wrong` 与 `the falloff IS the Mahalanobis distance...` 覆盖；e2e 断言校正曲线在固定偏移处高于朴素曲线
- **历史修正**：初稿把相对偏移当作绝对屏幕坐标传给 `footprintOpacity`，两条曲线全部塌到 0，图注显示 `0.000 / Infinity`——单测与 typecheck 全绿，只有看到实际截图才发现。现改为直接以偏移调用 `gaussianFalloff`
- **Caption 声明**：解析计算；说明 $r$ 是马氏距离，因此一个 $\sigma$ 处恰为 $e^{-1/2}\approx0.607$

## 7. `DepthIntoExtentFigure` — 这个捷径在什么情况下会露馅

- **学习问题**：朴素"丢掉深度分量"的规则在什么情况下失效、失效多少？
- **预期观察**：两幅图的虚线（朴素）**完全相同**，半轴都是 2.5 px，因此分不出球和针；校正半轴分别为 2.8 px 与 62.5 px，相差约 22 倍
- **呈现形式**：原创 SVG，两个同级 `<svg>` 共用 viewBox（`HALF_W=0.32`、`HALF_H=0.20`）
- **事实与精度依据**：`compareFootprints(1, 2, 0.01, σ_along)`；$\sigma_\text{along}=0.01$ 与 $0.5$ 两组
- **本轮修正**：面板标题字号曾写成 `15 * HALF_H / 20` = 0.15 个 viewBox 单位，实际不可见；改为 0.030 并置于椭圆行上方
- **Caption 声明**：同时说明"右图朴素把 62 px 长条画成 2.5 px 的点"与"左图两法仍有 1.118 倍差异（朴素规则只在光轴精确）"

## 8. `SplatBlendingFigure` — 前向 α 合成

- **学习问题**：为什么透射率与顺序无关、颜色与顺序有关？
- **预期观察**：图例固定近/中/远 alpha=0.30/0.35/0.45，按**近→远**遍历，权重为 0.300 / 0.245 / 0.205；三者之和 0.74975 加最终透射率 0.25025 等于 1
- **呈现形式**：原创 SVG（相机在左、三个椭圆共轴按深度排列 + 逐层数值），标注“合成遍历顺序：近 → 远”
- **数学检查**：图调用 `compositeFrontToBackDetail`；`each layer contribution is incoming transmittance times alpha` 检验逐层透射率、贡献及余量，验证反序的总和不变但逐项不同，并以近/远 alpha=0.1/0.9 反驳“近层贡献总最大”
- **本轮修正（原指控）**：初版把层级按"远→近"排列（α=0.45 打头）却仍在同一顺序累加透射率，于是最近图元的权重被乘成 0.10725。因为 (1−α) 的乘积可交换，**权重总和与最终透射率完全不变**，所以原有 106 项单测与 94 项浏览器测试全部通过。现按近→远遍历，图注同时给出错误顺序的三项权重作为对照
- **Caption 声明**：指出排序错误只表现为颜色偏差而非几何穿帮

## 9. `LinearizationLimitFigure` — 一阶近似何时失效

- **学习问题**：$\Sigma'=J\Sigma J^\top$ 在什么参数区间可信？
- **预期观察**：$\sigma_\text{along}\lesssim0.1$ 时预测与实测几乎重合；$0.5$ 时实测是预测的两倍以上；朴素线始终不变
- **数据来源**：`sampleProjectedPoints` 与 `empiricalCovariance`，每点 20000 样本，seed 20240513，丢弃 $z\le10^{-4}$
- **数学检查**：`the linearization is a tangent-space scale...` 与 `shrinking the depth extent converges...` 断言趋势与量级
- **Caption 声明**：解析数据 + 蒙特卡洛实测；说明这是本文的独立数值观察，不是论文实验数据的重绘
